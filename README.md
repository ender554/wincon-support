# WinCon Support

This is the public support and feedback tracker for WinCon, an Overwatch
composition-coaching app for Overwolf.

WinCon is currently in product planning and approval preparation. Public
testing has not started yet.

## Request support or share feedback

Use [GitHub Issues](https://github.com/ender554/wincon-support/issues) to:

- report a reproducible app problem;
- report an incorrect hero, map, mode, or roster interpretation;
- suggest a coaching or accessibility improvement;
- provide structured feedback about an explanation or recommendation.

Before opening an issue, search the existing issues for the same topic.

## Useful report details

Include:

- the WinCon app version;
- the Overwolf client version;
- the Overwatch mode and team format;
- the map and match phase;
- the behavior you expected;
- the behavior you observed;
- reproducible steps, when available.

## Protect player privacy

Remove or obscure:

- player names and BattleTags;
- account identifiers;
- private profile information;
- raw game-event payloads;
- screenshots containing player identity.

Use the dedicated WinCon support/privacy email for sensitive reports after
that address is published.

## Source repository

The WinCon application source is maintained in a separate private repository.
This repository contains public support material and issue discussions only.
